# SD2 Mod Studio — downloads

SD2 Mod Studio is a free Windows app for making your own **Steel Division 2** mods without editing game files by hand: divisions and battlegroups, unit and weapon changes, game rules and maps. The game's own files are never changed.

More about it: **https://www.5th-imperium.com/apps/sd2-mod-studio/**

This repository holds only the installers. The app's source code is not published.

## Download

Open **[the latest release](https://github.com/hap67/hap67-sd2-mod-studio-releases/releases/latest)** and download `SD2ModStudio-Setup-<version>.exe` under *Assets*.

**Windows will warn you.** The installer isn't signed by a publisher Windows knows, so you will see *Windows protected your PC*. Click **More info**, then **Run anyway**. Each release lists the installer's SHA-256 if you want to check the file.

**What the installer does**
- Installs for your Windows account only. No administrator rights needed.
- Adds SD2 Mod Studio to the Start menu, and an uninstaller to Windows Settings → Apps.
- Writes only to your mod folders and its own settings folder (`%LOCALAPPDATA%\SD2ModStudio`). It never changes the game's files.
- Updating: run the newer installer. Your mods, divisions and settings are kept.

**You need** Windows 10 (version 1809 or later) or Windows 11, and Steel Division 2 from Steam.

## Alpha: time-limited versions

SD2 Mod Studio will always be free. While it is in alpha, each version stops working 90 days after it was built; the app warns you 14 days and again 2 days before. The time limits are there to avoid support requests for outdated software as much as possible, and they will be removed in version 1.0. When a version expires, download the latest one here: nothing you made is lost.
